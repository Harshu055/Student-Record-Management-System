**#Student Record Management System#**

**##Description##**

A menu-driven Student Record Management System developed in C using Singly Linked Lists and Dynamic Memory Allocation. It provides operations to add, delete, display, modify, search, sort, and reverse student records, with file handling for data storage and retrieval.

**##Features##**

-Add new student records with automatic roll number allocation.

-Delete records by roll number or name.

-Display all student records.

-Modify student details.

-Sort records by name or percentage.

-Reverse the linked list.

-Delete all records.

-Save and load records using file handling.

-Technologies Used

**##C Programming##**

-Singly Linked Lists

-Structures and Pointers

-Dynamic Memory Allocation

-File Handling

-Makefile

**##Project Structure##**

-student.h – Structure definition and function declarations.

-stud_main.c – Main menu and program control.

-stud_add.c – Add student records.

-stud_del.c – Delete student records.

-stud_show.c – Display student records.

-stud_mod.c – Modify student records.

-stud_save.c – Save and load records.

-Makefile – Compile the project.
